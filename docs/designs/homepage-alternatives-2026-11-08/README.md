# Unpublished homepage alternatives

These are the three Tiling.ca homepage directions previewed on November 8, 2026:

- **Quiet luxury** — an editorial layout with serif typography and large room imagery.
- **Project first** — a practical layout that starts with the project type and city.
- **Material studio** — an image-led layout with an interactive material selector.

The owner requested previews only. No alternative has been approved for implementation or deployed to tiling.ca. A selected carousel view is not approval to replace the homepage.

Open `index.html` locally in a browser to compare the complete previews using the controls below the page. `source.fragment.html` is the editable original; it uses the conversation's variant-carousel and optional design-control helpers. The standalone preview includes a local carousel runtime. All imagery is embedded, and Google Fonts is the only external visual dependency. Forms and selectors are local demonstrations; they do not submit enquiries.

These files live under `docs/designs`, outside application routes and public assets. They are reference material, not the production homepage. The source uses existing illustrative/inspiration assets rather than evidence of completed customer projects.
